Data Wrangling with dplyr

Instructor-led tutorial using palmerpenguins

Author

Dr. Bigman (with lots of help from Allison Horst)

Overview

Overview

In this tutorial, we will use {dplyr} to practice core data-wrangling tasks in R. We will work with the penguins data from the palmerpenguins package.

By the end of the tutorial, you should be able to:

use filter() to keep observations that meet specified conditions; use select() to keep or remove variables; use relocate() to reorder variables without dropping columns; use rename() and rename_with() to change variable names; use mutate() to create or modify variables; combine group_by() with summarise() to calculate summaries for groups; and combine multiple {dplyr} functions with the pipe (|>) to build data-wrangling workflows.

Note

This lesson is an instructor-led adaptation inspired by Allison Horst’s Wrangling penguins: some basic data wrangling in R with dplyr LearnR tutorial. The structure and explanations here have been rewritten for a classroom Quarto workflow, and current dplyr syntax is used where the package has changed.

Source: https://allisonhorst.shinyapps.io/dplyr-learnr/

filter(): keep rows

Use filter() when you want to keep observations that satisfy one or more conditions.

The general structure is:

data |>
  filter(condition)

The pipe operator

The native R pipe, |>, can be read as “and then.” We call this the native version because R did not used to have a native version and just had a dplyr version, %>%. If you ever see %>%, it is the same thing.

penguins |>
  filter(species == "Chinstrap")

This means: start with penguins, and then filter the rows of observations with Chinstrap penguins.

  select(contains("length") & starts_with("bill"))

group_by() + summarise(): summaries by group

Often, you will want to summarize data so to find out certain things about your data. For the penguins example, we may want to know:

What is the mean body mass for each species? How many penguins were observed on each island? What is the mean flipper length for males and females within each species?

group_by() tells dplyr which groups should be treated separately. summarise() then calculates one or more summary statistics for each group.

Without grouping, summarise() returns an overall summary. If we run the code below, we get a mean mass for all penguins. But that is not very useful.

penguins |>
  summarise(
    mass_mean = mean(body_mass_g, na.rm = TRUE)
  )
# A tibble: 1 × 1
  mass_mean
      <dbl>
1     4202.

With grouping, the same calculation is performed separately for each group.

One summary by one group

Calculate mean body mass by species.

penguins |>
  group_by(species) |>
  summarise(
    mass_mean = mean(body_mass_g, na.rm = TRUE)
  )
# A tibble: 3 × 2
  species   mass_mean
  <fct>         <dbl>
1 Adelie        3701.
2 Chinstrap     3733.
3 Gentoo        5076.

na.rm = TRUE tells mean() to ignore missing values when calculating the mean.

Multiple summaries

Calculate mean and standard deviation of body mass by species.

penguins |>
  group_by(species) |>
  summarise(
    mass_mean = mean(body_mass_g, na.rm = TRUE),

The .groups = "drop" argument makes the returned table ungrouped after the summary is calculated. This is a good idea to do because after summarise(), you often want the resulting table to behave like a regular ungrouped data frame.

If grouping remains, later operations such as mutate(), filter(), or another summarise() may still be carried out separately within those groups, sometimes unintentionally.

Combine wrangling steps

Here, we want to understand the minimum and maximum flipper length for male Adelie penguins on each island. We will need to use filter, group_by, and summarise to calculate the minimum and maximum flipper length by island for male Adelie penguins. First, we have to filter species by Adelie, sex by male. Then we have to group_by island. Last, we have to summarise the flipper_length_mm by its maximum and minimum value using the max and min functions.

penguins |>
  filter(species == "Adelie", sex == "male") |>
  group_by(island) |>
  summarise(
    flip_max_length = max(flipper_length_mm, na.rm = TRUE),
    flip_min_length = min(flipper_length_mm, na.rm = TRUE)
  )
# A tibble: 3 × 3

Summary

The dplyr functions covered in this tutorial answer different types of data-wrangling questions:

Question Function
Which observations do I want? filter()
Which variables do I want? select()
Where should variables appear? relocate()
What should variables be called? rename()
What new variables do I need? mutate()
What summaries do I need by group? group_by() + summarise()
Can I repeat the same operation across variables? across()
How many observations are in each group? count()
Can I assign values based on several conditions? case_when()

The main idea is that these verbs can be chained together with |> to build a readable sequence of data-wrangling steps.
